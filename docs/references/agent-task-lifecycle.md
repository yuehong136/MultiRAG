# Agent 标签与后台执行生命周期

`canvas_type` 是不超过 32 字符的展示或分类标签，与决定执行模式的
`canvas_category` 独立。创建 Agent 时默认空字符串；更新时省略或传 `null`
保留原值，传空字符串清空。详情和列表均返回该字段，更新仍要求 owner 权限。
执行类别由调用者显式传递，不能从任意标签推导为数据流。

立即返回的 Webhook 由进程保留任务引用；执行结束后只将 DSL 和更新时间写回，
不会覆盖执行期间用户编辑的标题、标签等信息。写回使用任务自己管理的异步数据库
会话，不捕获请求会话或 ORM 对象。任务退出会关闭执行流；应用关闭时先取消并
等待这些任务，再释放工作流资源。该任务是进程内工作，进程被强制终止时不保证重放。

租户邀请邮件继续通过 FastAPI `BackgroundTasks` 在响应后发送，只传递独立的
字符串参数。单封邮件失败会记录安全错误并允许批次后续邮件继续；取消会继续传播。
邀请记录与邮件投递是两个结果，邮件失败不会回滚已经提交的邀请。

LocalLLM 的同步流每次调用独立管理 Jina 流及客户端。普通工作线程使用自己的
事件循环；调用线程已有运行中的循环时，使用临时线程承载独立循环，不嵌套驱动或
关闭调用者的循环。流完成、异常、取消或显式关闭时均执行流与客户端清理，随后关闭
本次循环及临时线程。调用者提前停止迭代时应显式关闭同步生成器。

文档任务通过存储适配器的严格读取接口读取源文件。`None` 表示对象不存在，进入
解析或 embedding 之前失败；空字节保持为空字节，由解析器决定空文档结果。读取失败
与缺对象分别报告安全错误，不把 bucket、对象键或供应商错误凭据写入任务消息。
普通分块任务先读取、解析源文件，再探测 embedding 模型和初始化索引。

定向验收见 `tests/integration/test_agent_lifecycle_source_contracts.py`：scratch SQL、
真实 Redis 与 MinIO，HTTP 标签保存及独立读回、请求 DB 释放后后台写回、缺对象的
失败状态及解析、模型和索引副作用边界。Jina 服务和真实邮件供应商需独立运行验收。
