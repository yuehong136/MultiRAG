# 可审查的旧记忆目标推荐

目标推荐帮助调用者找到值得与新来源一起对照的旧记忆。推荐本身不创建整理任务、候选、修订或覆盖记录，
不批准或发布内容。调用者明确选择目标后，继续使用既有[维护任务](memory-maintenance.md)或[增量计划](memory-incremental.md)。
调用前检查 `capabilities.maintenance.target_recommendations.supported`；存储适配范围仍由当前受管能力决定。

## 显式推荐

```http
POST /api/v1/memories/{memory_id}/maintenance-targets/recommendations
Content-Type: application/json

{
  "source_ids": ["9007199254740993"],
  "user_id": "subject",
  "agent_id": "assistant",
  "retrieval_mode": "hybrid",
  "limit": 5,
  "budget_tokens": 4096,
  "query_budget_tokens": 2048
}
```

请求最多指定 8 条已登记且有效的 RAW 来源，并提供精确的 user/agent 筛选；空字符串也是精确值，不表示全体。
来源必须与该主体范围匹配，跨会话可以推荐同主体的旧记忆。筛选条件不能授予租户或 Memory 访问权限。

`hybrid` 最多执行一次现有模型向量化，并融合至多 64 个向量命中与 128 条当前逻辑记忆的词面候选。
`lexical` 显式使用词面候选，不调用向量模型。两种模式都不调用聊天模型，也不根据模型生成的 ID 修改数据。
每次最多进一步核验 32 个候选、读取 128 条不同的实际投影；达到限制时返回省略量，不继续无界读取。
向量化沿既有模型用量计量；“只读”指不改变记忆、候选、任务及分析覆盖，并不表示模型调用免费。

默认查询来自指定来源，也可显式传入最多 4,096 字符的 `query` 聚焦长来源中的问题。两种查询都必须满足
`query_budget_tokens`（256–4,096，默认 2,048）；超出则拒绝，不静默截去尾部。
显式查询只决定检索方向，不能替代原始来源，也不能证明目标与新事实存在语义关系。

## 有界结果和依据

只推荐同 Memory、同主体范围内已登记且就绪的当前 entry；旧投影、撤回来源、身份不符或必要依据不完整的条目不能作为可用目标。
目标返回完整正文、逻辑 entry ID、修订/代际、当前物理消息 ID、正文与投影哈希、必要来源的版本、范围及哈希。
物理 ID 和推荐快照中的版本值使用十进制字符串。

`reasons` 表示向量排名或词面重合等检索依据，不是事实置信度或 verified 状态。
结果最多 8 项，完整响应受 `budget_tokens`（1,024–8,192）约束；放不下的目标明确计入省略，不把残缺正文当成可审查目标。
每个目标的来源依赖有上限，不能静默丢掉必要来源后继续使用。

响应分别给出查询、候选库存、结果预算的限制和省略原因。
`retrieval.inventory_complete` 只描述本次已登记、当前逻辑记忆的 SQL 候选窗口是否截断；
它不表示已经搜索全部物理历史，也不保证召回所有相关记忆。
向量命中可以通过当前消息映射进入候选，不受词面窗口前 128 条的限制。

## 选择与版本前置条件

推荐响应的 `confirmation` 是待确认的版本元数据，不是授权令牌。
用户明确勾选后，复制为现有创建/预览请求的 `target_preconditions`，其中 `targets` 只保留所选项，
`entry_ids` 必须恰好是这些目标的 ID。未选择的推荐不自动进入分析。

手动维护任务的 `source_ids` 还须包含推荐输入及所选旧目标的全部必要 RAW 来源。
输入和所选目标的必要来源并集最多 32 条。分别可用的备选目标不一定能同时选入；组合超限时明确拒绝，不裁掉依据。
增量计划复用原来的主要来源选择和必要上下文闭包；预览会检查推荐输入确实被纳入。
携带推荐前置条件时，主体筛选必须与推荐时的精确 user/agent 一致。会话筛选继续沿原计划语义约束来源及必要上下文；
跨会话对照应显式选择不限制会话，或使用明确列出来源的手动任务，界面不会自动扩大范围。
推荐输入、目标或必要来源的版本/代际/正文、实际投影或模型配置变化时，确认返回冲突，须重新推荐和审查。
不能删掉前置条件后把旧推荐当成仍有效的确认。
推荐是读取时的快照，不提供 SQL 与消息存储之间的原子快照；确认和执行仍须重新检查。
来源临时停用后合法重新启用时，可以重新推荐当前仍有效的旧记忆；停用前取得的旧确认不能跨代际继续使用。

创建后继续使用原操作 ID 恢复；相同创建操作返回已封存计划，不因后来内容变化而偷偷创建新版本。
任务执行、候选审核和发布仍沿现有来源检查、版本比较及恢复协议。
审核批准采用与事实核验属实分开，推荐及发布不会自行把内容标成 verified。

Web 复用维护和批次工作区：显式推荐、默认不勾选、展示完整旧正文及依据、明确应用所选目标，再预览和提交。
输入或范围变化会使当前选择失效；刷新和轮询不自动重新推荐或调用模型。

本功能不提供自动合并、自动覆盖、自动审核发布、定时触发或 Wiki。
